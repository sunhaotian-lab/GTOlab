# 飞书 MCP 使用示例

本文档提供使用飞书 MCP 的实际示例，帮助你快速上手。

## 前置条件

1. ✅ 已安装配置飞书 MCP 服务器（参考 MCP_GUIDE.md）
2. ✅ 已重启 Claude Code
3. ✅ MCP 服务器正常运行

---

## 示例 1：获取群聊消息

### 在 Claude Code 中输入：

```
请使用飞书 MCP 获取群聊 oc_abc123 的最近 50 条消息
```

### Claude 会做什么：

1. 自动识别需要使用 `mcp__feishu__get_messages` 工具
2. 调用 MCP 工具获取消息
3. 解析并展示消息列表

### 预期输出：

```
已获取 50 条消息：

1. [2024-01-06 10:30] 张三: 大家好
2. [2024-01-06 10:31] 李四: 你好！
...
```

## 示例 4：完整的消息追踪任务

### 在 Claude Code 中输入：

```
请帮我执行以下完整的消息追踪任务：

配置信息：
- 群聊 ID: oc_abc123
- 目标用户 ID: ou_def456
- 多维表格 app_token: bascn123456
- 数据表 ID: tbl789012

任务步骤：
1. 获取群聊最近 24 小时的消息
2. 筛选出目标用户的消息
3. 将每条消息保存到多维表格，包含以下字段：
   - 日期
   - 时间
   - 用户名
   - 消息内容
   - 消息类型
4. 报告执行结果
```

### Claude 会做什么：

1. **步骤 1**: 调用 MCP 获取消息
2. **步骤 2**: 筛选用户消息
3. **步骤 3**: 逐条保存到表格
4. **步骤 4**: 生成执行报告

### 预期输出：

```
✅ 任务执行完成

执行摘要：
- 获取消息总数: 150 条
- 目标用户消息: 25 条
- 成功保存: 25 条
- 失败: 0 条

详细信息：
1. [2024-01-06 09:00] 早上好 ✓
2. [2024-01-06 10:15] 项目进度如何？ ✓
...
25. [2024-01-06 18:30] 明天见 ✓

所有消息已保存到多维表格！
```

## 示例 6：定时任务脚本

虽然 MCP 主要用于交互式使用，但你也可以创建一个"提示词脚本"让 Claude 定期执行：

### 创建 `daily_tracker_prompt.txt`：

```
每天执行一次消息追踪任务：

1. 获取群聊 oc_abc123 昨天（从 00:00 到 23:59）的所有消息
2. 筛选用户 ou_def456 的消息
3. 保存到多维表格 bascn123456 的表 tbl789012
4. 发送执行报告到我的飞书消息

配置：
- 时区: Asia/Shanghai
- 格式: 日期、时间、用户名、消息内容、消息类型
```

然后每天在 Claude Code 中粘贴这个提示词，或者使用自动化工具（如 cron）调用 Claude API。

## 高级技巧

### 技巧 1：使用变量存储配置

在对话开始时：

```
请记住以下配置，后续任务会用到：

CHAT_ID = "oc_abc123"
USER_ID = "ou_def456"
BITABLE_APP = "bascn123456"
BITABLE_TABLE = "tbl789012"
```

然后在后续任务中：

```
使用上面的配置，追踪昨天的消息
```

### 技巧 2：创建快捷命令别名

```
创建别名：
- "每日追踪" = 获取 CHAT_ID 中 USER_ID 昨天的消息并保存到 BITABLE
- "实时查看" = 获取 CHAT_ID 最近 10 条消息
- "统计报告" = 生成本周的消息统计报告
```

然后就可以直接说：

```
执行"每日追踪"
```

### 技巧 3：错误处理

```
执行消息追踪任务，如果遇到错误：
1. 记录错误详情
2. 尝试重试（最多 3 次）
3. 如果仍然失败，发送错误通知到我的飞书
4. 保存执行日志到本地文件
```

## 最佳实践

### ✅ 推荐做法

1. **明确指定参数**：提供完整的 ID 和配置信息
2. **分步执行**：复杂任务分成多个步骤
3. **验证结果**：要求 Claude 展示执行结果
4. **错误处理**：提前说明遇到错误该怎么办

### ❌ 不推荐做法

1. **模糊描述**："帮我处理一下消息"（缺少具体信息）
2. **一次性大任务**：一次性要求处理上千条消息（容易超时）
3. **忽略错误**：不关注执行过程中的错误提示

## 故障排除

### 问题：MCP 工具不可用

**检查清单**：
- [ ] MCP 配置文件是否正确
- [ ] Claude Code 是否已重启
- [ ] Node.js 是否正常运行
- [ ] 网络连接是否正常

**测试命令**：
```bash
npx @larksuiteoapi/lark-mcp mcp -a YOUR_APP_ID -s YOUR_APP_SECRET
```

### 问题：权限错误

**原因**：飞书应用权限不足

**解决**：
1. 访问飞书开放平台
2. 检查应用权限配置
3. 确保权限已审批通过

### 问题：找不到消息

**可能原因**：
1. chat_id 错误
2. 时间范围内没有消息
3. 应用未加入群聊

**验证**：
```
请先获取群聊 oc_abc123 的基本信息
```

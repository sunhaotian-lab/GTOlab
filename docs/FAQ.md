# 常见问题解答 (FAQ)

## 配置相关

### Q1: 如何获取 App ID 和 App Secret？

**答：**
1. 访问 [飞书开放平台](https://open.feishu.cn/app)
2. 登录并创建企业自建应用
3. 在应用的"凭证与基础信息"页面可以找到

### Q2: config.json 文件应该放在哪里？

**答：**
放在项目根目录下，与 `main.py` 同级。可以复制 `config.example.json` 并重命名为 `config.json`。

### Q3: 时区设置有哪些选项？

**答：**
常用时区：
- `Asia/Shanghai` - 北京时间
- `Asia/Hong_Kong` - 香港时间
- `America/New_York` - 纽约时间
- `Europe/London` - 伦敦时间

完整列表见：https://en.wikipedia.org/wiki/List_of_tz_database_time_zones

## 权限相关

### Q4: 提示"权限不足"怎么办？

**答：**
1. 检查应用权限配置：
   - `im:message` 或 `im:message:read` - 读取消息
   - `im:chat` 或 `im:chat:read` - 读取群组信息
   - `bitable:app` - 多维表格权限
2. 确保权限已通过管理员审批
3. 尝试在飞书管理后台重新发布应用

### Q5: 应用需要哪些权限？

**答：**
最小权限集：
- **必需**: `im:message`, `im:chat`, `bitable:app`
- **可选**: `contact:user:read` (如果需要获取用户详细信息)

### Q6: 为什么有些权限申请不通过？

**答：**
1. 某些权限需要管理员审批
2. 敏感权限需要说明使用场景
3. 确保应用用途符合企业政策

## ID获取相关

### Q7: 如何快速获取 chat_id 和 user_id？

**答：**
使用辅助工具：
```bash
python tools/get_ids.py
```

或者手动获取：
- **chat_id**: 打开群设置，查看URL中的 `oc_xxxxx`
- **user_id**: 在飞书管理后台的用户管理中查看

### Q8: chat_id 的格式是什么样的？

**答：**
通常是以 `oc_` 开头的字符串，例如：`oc_1234567890abcdef`

### Q9: 能同时追踪多个用户吗？

**答：**
当前版本只支持单个用户。如需追踪多个用户，可以：
1. 运行多个实例，使用不同的配置文件
2. 修改代码，将 `target_user_id` 改为列表

## 多维表格相关

### Q10: 多维表格的字段名必须一致吗？

**答：**
是的。默认字段名为：
- 日期
- 时间
- 用户名
- 消息内容
- 消息类型
- 消息ID

如需自定义字段名，需修改 `message_tracker.py` 中的字段映射。

### Q11: 如何修改字段名？

**答：**
编辑 `message_tracker.py` 中的 `parse_messages_to_records` 方法：

```python
record = {
    "自定义日期": dt.strftime("%Y-%m-%d"),  # 改为你的字段名
    "自定义时间": dt.strftime("%H:%M:%S"),
    # ... 其他字段
}
```

### Q12: 能追踪历史消息吗？

**答：**
可以。使用命令：
```bash
# 追踪指定日期
python main.py --once --date 2024-01-01

# 追踪指定时间段
python main.py --once --start-time "2024-01-01 00:00:00" --end-time "2024-01-31 23:59:59"
```

## 运行相关

### Q13: 如何测试配置是否正确？

**答：**
运行单次测试：
```bash
python main.py --once
```

### Q14: 定时任务没有自动运行怎么办？

**答：**
1. 检查程序是否在运行：`ps aux | grep main.py`
2. 查看日志输出，确认下次运行时间
3. 检查时间和时区配置是否正确
4. 确保系统时间准确

### Q15: 如何修改运行时间？

**答：**
编辑 `config.json` 中的 `schedule.run_time`：
```json
{
  "schedule": {
    "run_time": "22:00",  // 修改为你想要的时间
    "timezone": "Asia/Shanghai"
  }
}
```

### Q16: 能手动触发一次任务吗？

**答：**
可以。使用 `--once` 参数：
```bash
python main.py --once
```

## 消息相关

### Q17: 支持哪些消息类型？

**答：**
- ✅ 文本消息
- ✅ 富文本消息
- ✅ 图片（记录为 `[图片]`）
- ✅ 文件（记录为 `[文件: xxx]`）
- ✅ 语音、视频（记录为 `[语音]`、`[视频]`）

### Q18: 图片和文件内容会被下载吗？

**答：**
不会。默认只记录消息类型和基本信息。如需下载附件，需要修改代码。

### Q19: 如何过滤特定关键词的消息？

**答：**
修改 `message_tracker.py` 的 `parse_messages_to_records` 方法：

```python
for msg in messages:
    content = self.client.parse_message_content(msg)

    # 添加关键词过滤
    keywords = ["重要", "紧急"]
    if not any(kw in content for kw in keywords):
        continue  # 跳过不包含关键词的消息

    # ... 继续处理
```

### Q20: 获取不到消息怎么办？

**答：**
检查清单：
- [ ] 应用已添加到目标群聊
- [ ] chat_id 正确
- [ ] 时间范围内确实有消息
- [ ] 应用有读取消息的权限
- [ ] 权限已通过审批

## 错误排查

### Q24: 报错 "module not found"

**答：**
安装依赖：
```bash
pip install -r requirements.txt
```

### Q25: 报错 "config.json not found"

**答：**
1. 确保 config.json 在项目根目录
2. 检查文件名拼写（区分大小写）
3. 或使用 `--config` 参数指定路径

### Q26: API 请求失败怎么办？

**答：**
常见原因：
1. **Token过期**: 程序会自动刷新，通常不会出现
2. **权限不足**: 检查权限配置
3. **网络问题**: 检查网络连接
4. **API限流**: 减少请求频率

### Q27: 如何查看详细错误日志？

**答：**
1. 查看控制台输出
2. 检查 `logs/tracker.log`（如果配置了文件日志）
3. 使用 `--debug` 参数（需要修改代码添加此功能）

## 性能相关

### Q28: 会对飞书服务器造成负担吗？

**答：**
不会。程序：
- 使用分页获取，避免单次请求过多数据
- 添加了请求延迟（0.5秒），避免频繁请求
- 使用批量写入，减少API调用

### Q29: 能追踪多少历史消息？

**答：**
理论上没有限制，但建议：
- 单次任务不超过一个月的数据
- 历史数据可以分批处理
- 注意API调用配额限制

### Q30: 如何优化性能？

**答：**
1. 使用缓存减少重复API调用
2. 异步处理（需要修改代码）
3. 合理设置时间范围

## 安全相关

### Q31: config.json 包含敏感信息，如何保护？

**答：**
1. 不要提交到版本控制：`.gitignore` 已包含
2. 设置文件权限：`chmod 600 config.json`
3. 使用环境变量替代（高级用法）

### Q32: 会泄露群聊隐私吗？

**答：**
不会。数据流向：
- 飞书服务器 → 本程序 → 飞书多维表格
- 数据不会发送到第三方
- 建议在可信环境运行

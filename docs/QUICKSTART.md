# 快速开始指南

本指南将帮助你在10分钟内配置并运行飞书消息追踪器。

## 第一步：创建飞书应用

### 1.1 访问飞书开放平台

访问 https://open.feishu.cn/app 并登录你的飞书账号。

### 1.2 创建应用

1. 点击右上角"创建企业自建应用"
2. 填写应用信息：
   - **应用名称**：飞书消息追踪器（或任意名称）
   - **应用描述**：自动追踪群聊消息
   - **应用图标**：可选
3. 点击"创建"

### 1.3 获取凭证

创建成功后，在应用的"凭证与基础信息"页面：
- 复制 **App ID**
- 复制 **App Secret**

⚠️ **重要**：App Secret 是敏感信息，请妥善保管，不要泄露。

## 第二步：配置应用权限

在应用管理页面，点击左侧"权限管理"。

### 2.1 添加消息权限

搜索并开通以下权限：

| 权限名称 | 权限代码 | 用途 |
|---------|---------|------|
| 读取群聊消息 | `im:message` | 获取群聊消息内容 |
| 获取群组信息 | `im:chat` | 获取群聊信息 |

### 2.2 添加多维表格权限

搜索并开通以下权限：

| 权限名称 | 权限代码 | 用途 |
|---------|---------|------|
| 查看、评论和编辑多维表格 | `bitable:app` | 写入数据到多维表格 |

### 2.3 申请权限审批

1. 添加权限后，点击"申请发布"
2. 等待管理员审批（如果你是管理员，可以直接审批）
3. 审批通过后，权限才会生效

## 第三步：准备多维表格

### 3.1 创建多维表格

1. 在飞书中创建一个新的多维表格
2. 创建一个数据表，包含以下字段：

| 字段名 | 字段类型 |
|--------|---------|
| 日期 | 日期 |
| 时间 | 文本 |
| 用户名 | 文本 |
| 消息内容 | 文本 |
| 消息类型 | 文本 |
| 消息ID | 文本 |

### 3.2 获取多维表格ID

打开多维表格，查看浏览器地址栏：

```
https://xxx.feishu.cn/base/bascnXXXXXXXXXXXXXXXXX?table=tblXXXXXXXXXXXXXX
```

- `bascnXXXXXXXXXXXXXXXXX` 是 **app_token**
- `tblXXXXXXXXXXXXXX` 是 **table_id**

## 第四步：将应用添加到群聊

1. 打开要追踪的飞书群聊
2. 点击群设置 > 群机器人 > 添加机器人
3. 选择你刚创建的应用
4. 确认添加

## 第五步：获取必要的ID

### 5.1 获取群聊ID (chat_id)

方法1：从群设置URL获取
- 打开群设置，查看浏览器地址栏
- 地址中包含的 `oc_xxxxx` 就是 chat_id

方法2：使用辅助工具
```bash
python tools/get_ids.py
```
选择"1. 获取群聊列表"即可看到所有群聊的ID。

### 5.2 获取用户ID (user_id)

使用辅助工具：
```bash
python tools/get_ids.py
```
选择"2. 获取用户列表"即可看到所有用户的ID。

## 第六步：配置应用

### 6.1 复制配置文件

```bash
cp config.example.json config.json
```

### 6.2 编辑配置文件

打开 `config.json`，填入你的配置：

```json
{
  "feishu": {
    "app_id": "cli_xxxxxxxx",        // 第一步获取的App ID
    "app_secret": "xxxxxxxx"          // 第一步获取的App Secret
  },
  "tracker": {
    "chat_id": "oc_xxxxxxxx",         // 第五步获取的群聊ID
    "target_user_id": "ou_xxxxxxxx",  // 第五步获取的用户ID
    "bitable_app_token": "bascnxxxx", // 第三步获取的表格token
    "bitable_table_id": "tblxxxx"     // 第三步获取的数据表ID
  },
  "schedule": {
    "run_time": "23:00",              // 每天运行时间
    "timezone": "Asia/Shanghai"       // 时区
  }
}
```

## 常见问题排查

### Q1: 提示"权限不足"

**解决方案：**
1. 检查应用权限是否已添加并审批通过
2. 确认应用已添加到目标群聊
3. 尝试重新安装应用到群聊

### Q2: 获取不到消息

**解决方案：**
1. 确认chat_id是否正确
2. 确认时间范围内是否有消息
3. 使用 `tools/get_ids.py` 工具验证群聊ID

### Q3: 无法写入多维表格

**解决方案：**
1. 检查bitable_app_token和table_id是否正确
2. 确认多维表格字段名称与代码中定义的一致
3. 确认应用有多维表格的写入权限

### Q4: 找不到目标用户的消息

**解决方案：**
1. 使用 `tools/get_ids.py` 确认user_id是否正确
2. 检查时间范围内该用户是否有发言
3. 可以先不筛选用户，看是否能获取到所有消息

## 高级用法

### 追踪指定日期的消息

```bash
# 追踪2024年1月1日的消息
python main.py --once --date 2024-01-01
```

### 追踪指定时间段的消息

```bash
# 追踪指定时间段
python main.py --once --start-time "2024-01-01 09:00:00" --end-time "2024-01-01 18:00:00"
```

### 使用自定义配置文件

```bash
python main.py --config my_config.json --once
```
